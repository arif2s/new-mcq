📚 Help & Documentation

🎮 Quiz Modes

  • 📝 Test Mode: Auto-advances quickly. Explanations shown at the end.
  • 📖 Learn Mode: Shows detailed explanations immediately after answering.
  • 🎯 Target Mode: Quiz runs infinitely until you hit your target correct count.

🧠 Spaced Repetition

Uses the FSRS algorithm. Questions answered incorrectly or slowly will appear more frequently in future sets. Toggle this in the Quiz Configuration menu.

🏅 Rank Simulation

Estimates exam percentiles based on projected marks. Click "Edit Rank Data" in the Dashboard to map your own competitive exam cutoffs.
